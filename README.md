# US States guessing game 🎮

This is a US states guessing game. The python application is using the standard library of python ([turtle](https://docs.python.org/3/library/turtle.html) and [csv](https://docs.python.org/3/library/csv.html))
to let you guess the names of US states. After entering the name of an existing state, the name of the state will be displayed on the map for you.


The csv file contains the names of the states and the according coordinates on the map which the application uses to draw the
name on the map.
---
Simple but fun game. 👾
